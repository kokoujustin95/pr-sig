Mise à jour GS SIGMA — connexion e-mail/identifiant et confirmation

- Connexion possible avec l'identifiant habituel OU l'adresse e-mail du compte, avec le même mot de passe.
- Pour les comptes autres que l'administrateur principal, un code à 6 chiffres est envoyé par e-mail après validation du mot de passe.
- Le code s'affiche dans un écran séparé inspiré de l'interface fournie, expire après 10 minutes et le renvoi est temporisé.
- L'administrateur principal conserve l'accès direct sans code e-mail.
- L'ajout/modification d'un étudiant conserve le sélecteur de classe obligatoire. La classe cochée est enregistrée dans la fiche de l'étudiant.

Configuration nécessaire pour l'envoi des codes sur Render :
- SMTP_USER : compte e-mail d'envoi
- SMTP_PASS : mot de passe SMTP ou mot de passe d'application
- SMTP_FROM : adresse expéditrice
- Facultatif : SMTP_HOST (par défaut smtp.gmail.com), SMTP_PORT (par défaut 587), SMTP_SECURE (par défaut false)

Après déploiement, vérifier que DATABASE_URL est toujours configurée et tester :
1. Connexion par identifiant et par e-mail.
2. Réception et validation du code pour un compte non principal.
3. Connexion directe de l'administrateur principal.
4. Création d'un étudiant avec sélection de classe, puis vérifier sa fiche après actualisation.
